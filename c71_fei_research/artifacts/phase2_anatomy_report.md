## 2. Теорема обобщённого листового де-алиасинга: строгий вывод и негативный вердикт

Рассмотрим обобщение Вектора A2, где на каждом непересекающемся подкубе $C_j \subseteq g_0^{-1}(0)$ коразмерности $r_j$ ($\mu(C_j) = 2^{-r_j}$) вместо одиночного литерала $y_j$ подставляется произвольная булева функция $h_j(y^{(j)})$ на свежих, попарно непересекающихся блоках переменных $y^{(1)}, \dots, y^{(k)}$:
$$F\bigl(x, y^{(1)}, \dots, y^{(k)}\bigr) \;=\; g_0(x) + \sum_{j=1}^k \mathbf{1}_{C_j}(x)\, h_j\bigl(y^{(j)}\bigr).$$

### 2.1. Случай 1: Сбалансированные листья ($\hat{h}_j(\emptyset) = 0$) — строгий барьер выпуклости `[VERIFIED]`

Поскольку $\hat{h}_j(\emptyset) = 0$, разложение $h_j(y^{(j)}) = \sum_{T \neq \emptyset} \hat{h}_j(T)\chi_T(y^{(j)})$ содержит только непустые характеры $T \neq \emptyset$. Индикатор $\mathbf{1}_{C_j}(x)$ имеет ровно $2^{r_j}$ ненулевых Фурье-коэффициентов на подмножествах $S \subseteq \mathrm{Fixed}(C_j)$ с одинаковым модулем $2^{-r_j}$ и средним размером $\mathbb{E}[|S|] = r_j/2$. Произведения $\chi_S(x)\chi_T(y^{(j)})$ для разных $j$ и для $g_0(x)$ попарно ортогональны и не пересекаются, откуда получаются **точные формулы**:
$$\Delta I_j = \sum_{S, T \neq \emptyset} (|S| + |T|)\,2^{-2r_j}\hat{h}_j(T)^2 = 2^{-r_j}\!\left(\frac{r_j}{2} + I(h_j)\right),$$
$$\Delta H_j = \sum_{S, T \neq \emptyset} 2^{-2r_j}\hat{h}_j(T)^2\bigl(2r_j - \log_2 \hat{h}_j(T)^2\bigr) = 2^{-r_j}\bigl(2r_j + H(h_j)\bigr).$$

Сравнивая с базовой функцией $F_{\text{lit}}$ на чистых литералах ($I(y_j) = 1, H(y_j) = 0$, с параметрами $I_{\text{base}}, H_{\text{base}}, L_{\text{base}} = \frac{H_{\text{base}}}{I_{\text{base}} - 1}$):
$$\delta I_j := \Delta I_j - \Delta I_j^{\text{lit}} = 2^{-r_j}\bigl(I(h_j) - 1\bigr) \ge 0, \qquad \delta H_j := \Delta H_j - \Delta H_j^{\text{lit}} = 2^{-r_j}\,H(h_j) \ge 0.$$
Отсюда **предельная отдача** каждого листа равна в точности $\frac{\delta H_j}{\delta I_j} = \frac{H(h_j)}{I(h_j) - 1} = L(h_j)$, а итоговое отношение есть **точная выпуклая комбинация**:
$$L(F) = \frac{(I_{\text{base}} - 1)\,L_{\text{base}} + \sum_{j=1}^k 2^{-r_j}\bigl(I(h_j) - 1\bigr)\,L(h_j)}{(I_{\text{base}} - 1) + \sum_{j=1}^k 2^{-r_j}\bigl(I(h_j) - 1\bigr)} \;\le\; \max\Bigl(L_{\text{base}},\; \max_{1 \le j \le k} L(h_j)\Bigr).$$

> **Вывод (честный негативный результат):** Подстановка сбалансированных листьев $h_j$ на свежие переменные — это в точности частный случай Вектора A0 (блочной композиции сбалансированных функций $F_{\text{lit}}(x, h_1(y^{(1)}), \dots, h_k(y^{(k)}))$, где $\mathrm{Inf}_{y_j}(F_{\text{lit}}) = 2^{-r_j}$). Подстановка повышает $L$ строго тогда и только тогда, когда $L(h_j) > L_{\text{base}}$, но при этом сам лист $h_j$ уже строго лучше $F$! В частности, $h_j = F_{\text{lit}}$ оставляет $L(F) = L_{\text{base}}$ тождественно неизменным.

**Численная проверка через [`exact_verifier.py`](file:///e:/эксперименты/исследования/c71_fei_research/src/exact_verifier.py) (`diff = 0.0`):**
- $Q_2$ ($L_{\text{base}} = 6.0$) + два листа $h_1 = h_2 = \mathrm{MAJ}_3$ ($L = 4.0$, $n = 8$): Tier 1 полный FWHT даёт $I = 7/4$, $L_{\text{cert}} = 5.333333333333\ldots = \frac{16}{3}$, формула и выпуклая комбинация $\frac{0.5\cdot 6.0 + 0.25\cdot 4.0}{0.75} = \frac{16}{3}$ (`diff = 0.00e+00`).
- $Q_2$ ($L_{\text{base}} = 6.0$) + два листа $g_3'$ ($L = 6.3470675$): $L(F) = 6.1334875 \in (6.0, 6.3470675)$ — строго ниже самого листа $g_3'$.

### 2.2. Случай 2: Несбалансированные листья ($\mu_j = \hat{h}_j(\emptyset) \neq 0$, $\sum_j 2^{-r_j}\mu_j = 0$) `[VERIFIED]`

Разлагая $h_j = \mu_j + h_j^{\ge 1}$ с дисперсией $V_j = 1 - \mu_j^2$ и непустой энтропией $H^{\ge 1}(h_j) = -\sum_{T\neq\emptyset} \hat{h}_j(T)^2\log_2 \hat{h}_j(T)^2$, получаем эффективное ядро $g_{\text{eff}}(x) = g_0(x) + \sum_j \mu_j \mathbf{1}_{C_j}(x)$ и точные ортогональные вклады:
$$\Delta I_j^{\ge 1} = 2^{-r_j}\!\left(\frac{r_j}{2} V_j + I(h_j)\right), \qquad \Delta H_j^{\ge 1} = 2^{-r_j}\bigl(2r_j V_j + H^{\ge 1}(h_j)\bigr).$$

**Численная верификация и тест на `AG(2,3)`:**
- На $Q_2 + (\mathrm{AND}_2, \mathrm{OR}_2)$ ($n=6$): полный Tier 1 FWHT даёт $I = 3/2$, $L_{\text{cert}} = 5.933834373377\ldots < 6.0$; формула выше даёт `5.93383437337740` (`diff = 0.00e+00`).
- Полный скан **12 несбалансированных монотонных пар листьев** (`AND_m/OR_m` для $m=2..6$, `lex_3/8`, `lex_1/8`, `lex_5/16`, `lex_7/16`, `lex_3/16`, `Tribes(2,2)/Dual`, `Const(-1/+1)`) по 1–4 парам подкубов `AG(2,3)` ($d=9$, $r_j=8$): **0 улучшений над `6.521845710923`** (все дают $\Delta L < 0$). Причина: ненулевое смещение $\mu_j \neq 0$ уменьшает дисперсию подкуба $V_j = 1 - \mu_j^2$, мгновенно сжигая $2^{-r_j}\cdot 2r_j \mu_j^2$ энтропии ($16\mu_j^2/256$ на `AG(2,3)`), что не компенсируется изменением спектра $g_{\text{eff}}$.

> **Итог для архитектуры Фазы 2:** Не тратить ресурсы GPU на замену ортогональных литералов $y_j$ сложными листьями $h_j(y^{(j)})$. Превзойти `6.52184571` можно только **изменением самого ядра $g_0$ в $d \ge 10$** (более сильные перекрёстно-пересекающиеся гиперграфы / асимметричные возмущения ядра + чистый Вектор A2 на максимальных подкубах).
